⚠️ PERNYATAAN PENAFIAN TANGGUNG JAWAB (DATA LOSS DISCLAIMER)

Aplikasi Teman Kasir beroperasi secara 100% Offline-First (Full Local Storage) menggunakan basis data lokal SQLite di perangkat Anda. Seluruh riwayat transaksi kasir, katalog produk, catatan keuangan, rekap kas, dan konfigurasi meja makan tersimpan secara fisik di memori perangkat pengguna.

Pihak pengembang TIDAK BERTANGGUNG JAWAB atas kehilangan sebagian atau seluruh data usaha yang disebabkan oleh:

Tindakan pencopotan pemasangan (uninstall) aplikasi.

Pembersihan data (Clear Storage/Clear Data) dari menu pengaturan Android.

Kerusakan perangkat keras (hardware failure), reset ke setelan pabrik (factory reset), atau hilangnya perangkat.

Kesalahan operasional atau kelalaian pengguna.

1. Arsitektur Penyimpanan 100% Offline Lokal

Kami menghormati kedaulatan data dan kerahasiaan bisnis Anda:

Penyimpanan Lokal Eksklusif: Seluruh transaksi harian, nomor pesanan meja, modal kas kasir, harga modal, dan keuntungan tersimpan di database lokal perangkat Anda.

Tanpa Sinkronisasi Cloud Otomatis: Aplikasi tidak mengunggah nota transaksi, omzet harian, maupun katalog produk ke server cloud terpusat pihak ketiga.

Kendali Penuh di Tangan Pengguna: Anda memegang kendali penuh atas integritas dan fisik data yang ada di dalam perangkat Anda.

2. Data yang Dikumpulkan Saat Registrasi

Untuk kepentingan aktivasi lisensi usaha, verifikasi identitas outlet, dan pencegahan penyalahgunaan akun, aplikasi mengirimkan notifikasi saat pendaftaran akun outlet baru melalui protokol aman HTTPS/TLS ke sistem webhook Telegram pengembang:

Data Usaha: Nama Usaha / Outlet dan Kode Bisnis (Business ID).

Data Pemilik: Nama Lengkap Pemilik (Owner), Alamat Email, Nomor WhatsApp/Telepon, serta Username.

Jaminan Privasi: Data registrasi ini hanya digunakan untuk keperluan administrasi lisensi dan komunikasi bantuan teknis. Kami tidak menjual, menyewakan, atau membagikan data registrasi tersebut kepada pihak ketiga untuk kepentingan periklanan atau pemasaran.

3. Fitur Pencadangan Mandiri (Backup Berbayar)

Mengingat arsitektur penyimpanan bersifat lokal:

Pengguna sangat disarankan untuk melakukan pencadangan data (backup) secara rutin.

Teman Kasir menyediakan fitur pencadangan data mandiri dengan skema sekali bayar per pencadangan (one-time paid backup).

Berkas arsip cadangan yang dihasilkan dapat diekspor dan disimpan oleh pengguna ke media eksternal yang aman, seperti Google Drive pribadi, penyimpanan flashdisk/USB, atau email pengguna.

4. Sistem Lisensi PRO Offline

Paket berlangganan fitur PRO diaktifkan menggunakan token kriptografi luring (HMAC-SHA256):

Token dibuat oleh tim pengembang setelah konfirmasi pembayaran manual dan diverifikasi secara lokal di perangkat tanpa membutuhkan koneksi server berkelanjutan.

Aplikasi mencatat hash token yang telah digunakan dalam tabel database lokal (t_used_activation_codes) untuk mencegah pemakaian ulang (anti-replay guard).

5. Izin Perangkat (Permissions)

Aplikasi hanya meminta izin perangkat yang esensial untuk fungsi kasir:

Akses Jaringan (INTERNET): Digunakan saat proses pendaftaran outlet untuk mengirim notifikasi registrasi ke pengembang serta membuka tautan email bantuan.

Bluetooth (BLUETOOTH, BLUETOOTH_CONNECT, BLUETOOTH_SCAN): Digunakan untuk memindai dan mencetak struk transaksi via printer thermal Bluetooth.

6. Penghapusan Data & Akun

Penghapusan Data Lokal: Pengguna dapat menghapus seluruh data transaksi, riwayat kasir, dan katalog produk kapan saja dengan melakukan Uninstall aplikasi atau memilih Clear Data pada menu pengaturan aplikasi di perangkat Android.

Penghapusan Catatan Registrasi: Jika Anda ingin menghapus arsip data identitas outlet yang pernah didaftarkan pada sistem notifikasi pengembang, silakan ajukan permohonan tertulis melalui email resmi kami.
